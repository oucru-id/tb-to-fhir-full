# Test data

Everything here is either synthetic or public. There is no patient data.

| Path | Used by | Content |
|---|---|---|
| `vcf/*.vcf`, `samplesheet_vcf.csv` | `-profile test_vcf` | Synthetic VCFs. Variants are copied from the WHO catalogue, plus lineage barcode SNPs; depths and qualities are invented. Generated by `tests/fixtures/make_fixtures.py`. |
| `stub/*`, `samplesheet_stub.csv` | `-profile test_stub` | Empty placeholder inputs; stub runs never read them. |
| `illumina/ERR1873531_targets_{1,2}.fastq.gz`, `samplesheet_test.csv` | `-profile test` | A subset of a public ENA run (below). |

## `illumina/`: ERR1873531 subset

| | |
|---|---|
| Run | [ERR1873531](https://www.ebi.ac.uk/ena/browser/view/ERR1873531) |
| Study | [PRJEB14199](https://www.ebi.ac.uk/ena/browser/view/PRJEB14199) |
| Sample | SAMEA95413918, *Mycobacterium tuberculosis* |
| Platform | Illumina HiSeq 2000, paired-end, public since 2017-03-07 |
| Full run | 5,430,910 read pairs, MDR-TB (TBtoFHIR 1.6 and 2.0) |

How the subset was made:
1. The full run was aligned to H37Rv with this pipeline.
2. Read pairs with at least one primary alignment overlapping the WHO resistance targets
   (`who_targets.bed`) or a lineage barcode site ±60 bp were kept.
3. These were downsampled to about 30× (`samtools view -s 42.147`) and written back to FASTQ.

The result is 83,589 read pairs over 263 kb. Only reads that align to *M. tuberculosis* are
included.

Data from ENA are freely available. Please cite the study above if you reuse them.
